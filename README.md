# AO2---Dashboard-HTML-CSS-JS
Atividade da disciplina de Programação Web 2026.2/ Unicap - Sistemas para Internet
🎮 GameHub - Dashboard Steam & E-sports

🚀 Sobre o Projeto
O **GameHub** é um painel de controlo interativo voltado para o mercado de jogos da Steam e competições globais de E-sports. A aplicação apresenta métricas consolidadas em tempo real, gráficos dinâmicos de alta performance e um sistema completo de gestão (*CRUD*) sincronizado com o Back4App[cite: 3].

---

## 🛠️ Tecnologias Utilizadas
* **HTML5 & Tailwind CSS** (com design system inspirado na estética *Linear/Graphite*).
* **JavaScript (ES6+)** para manipulação do DOM, lógica de filtros e integração de APIs.
* **Chart.js** para renderização de gráficos interativos (Linha, Rosca e Barras).
* **Back4App (Parse REST API)** e **LocalStorage** para o funcionamento do CRUD de metas.
* **AwesomeAPI** para conversão de moedas (USD, BRL e EUR) em tempo real.

---

## 📋 Requisitos Atendidos da A02
1. **Dashboard com Chart.js:** 3 tipos de gráficos funcionais (Evolução de CCU, Distribuição por Gênero e Premiações por Jogo).
2. **Interatividade Avançada:** Filtros combinados em tempo real (por ano, género, busca por texto e conversor de moeda)
3. **CRUD Completo:** Operações de Criar, Listar, Editar e Excluir metas e torneios de e-sports integradas ao Back4App.
4. **API Pública de Terceiros:** Consumo de taxas de câmbio da AwesomeAPI com suporte a CORS.
5. **Responsividade:** Layout totalmente otimizado e adaptável para computadores e dispositivos móveis.
